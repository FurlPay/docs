## 5. Comparable: RedotPay on AWS

RedotPay is the closest operational parallel in the AWS ecosystem. Both
companies build stablecoin payment infrastructure with card issuing.

| Metric | RedotPay | FurlPay (current) |
| :--- | :--- | :--- |
| Founded | April 2023 | 2024 |
| Users | 6M+ verified | Early stage |
| Funding | $194M total | Pre-seed |
| Valuation | ~$2B (Dec 2025) | — |
| AWS deployment | Entire stack on AWS from week 1 | AWS account set up; no production workloads |
| Card network | Visa (live) | Designed, switched off; no issuer contracted |
| AI features | Exploring SageMaker | Claude Haiku 4.5 via Anthropic API |
| Travel vertical | None | Core product (flights, hotels, crypto payments) |

RedotPay deployed on AWS in one week and now processes $10B+ in annualized
payment volume. AWS published RedotPay as an official case study. FurlPay's
differentiators are its travel vertical, AI-native architecture, and agentic
finance capabilities.

## 6. AWS Activate — program summary

For reference during the Cyrus call.

| Tier | Credits | Requirement |
| :--- | :--- | :--- |
| Founders | $1,000–$5,000 | Self-funded, company website, professional email |
| Portfolio | Up to $200,000 | Affiliated with an AWS Activate Provider (Org ID required) |

**Restrictions:** credits cannot be used for cryptocurrency mining. All other
Web3 infrastructure workloads (payments, dApps, nodes, analytics) are eligible.

FurlPay's eligible workloads: stablecoin payment infrastructure, virtual card
issuing, AI financial intelligence (Bedrock/SageMaker), travel booking engine,
crypto-to-fiat processing, API infrastructure.
