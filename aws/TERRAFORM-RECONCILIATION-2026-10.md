# Terraform and Architecture Reconciliation, October 2026

> **Status, 22 October 2026.** A comparison of the AWS Terraform in the application repository with the [target architecture](../docs/ENTERPRISE-ARCHITECTURE-2026-2027.md). Inspected on the newest infrastructure branch (`feat/resilience-hardening` at `b596d9db`, which adds three-AZ networking on top of the production line `7a392b87`). **The Terraform has never been applied. No AWS resource described here exists.** No Terraform was changed as part of this review.

## What already matches

| Area | Terraform | Matches target |
| :--- | :--- | :--- |
| Edge | CloudFront distribution; ALB security group accepts 443 only from CloudFront's origin-facing managed prefix list; listener forwards only with the secret origin-verify header, otherwise a fixed 404 | Yes |
| Network | VPC across three Availability Zones (`az_count = 3`); public, private and isolated subnets; S3 gateway endpoint and interface endpoints; VPC flow logs | Yes |
| Task boundaries | Tasks accept port 3000 only from the ALB; egress HTTPS only, plus 5432/6379 inside the VPC when the AWS data plane is enabled | Yes |
| Database boundary | Aurora accepts 5432 only from the task security group; storage encrypted with the environment's KMS key | Yes |
| Database sizing (prod) | Aurora PostgreSQL 16.4, Serverless v2, 2–16 ACU, `multi_az = true`, `deletion_protection = true`, 35-day backup retention, Performance Insights | Yes |
| Compute (prod) | ECS Fargate, `desired_count = 3` | Yes |
| Secrets | Secrets Manager entries injected by the execution role, never in the task definition; placeholders refused at boot | Yes |
| Schedules | EventBridge rules → API destinations using **POST**, with an SQS dead-letter queue | Yes, for the five jobs it defines |
| Organization | CloudTrail with an Object Lock bucket, AWS Config, GuardDuty, Security Hub, service control policies | Yes |

The module **defaults** for `multi_az` and `deletion_protection` are `false`, but the production environment sets both to `true`. An earlier version of these docs said they had to be set for production; that was wrong and is corrected.

## Mismatches

Each row: **current → target → required action → validation → risk.**

| # | Current configuration | Target | Required engineering action | Validation | Risk |
| :--- | :--- | :--- | :--- | :--- | :--- |
